# EduBot — AI-Powered Learning Platform

## What is EduBot?

EduBot is an all-in-one AI-powered educational platform built for computer science and engineering students. It combines intelligent assessments, hands-on practical tools, and real-time feedback into a single seamless experience — so students can learn by doing, not just reading.

The platform is built on a MERN stack (MongoDB, Express, React, Node.js) with a Python/FastAPI backend powering the AI and speech analysis features, and Google Gemini as the core AI engine.

---

## What the Platform Does

### 1. AI-Generated Quizzes & MCQs
Students can practice subject-specific multiple-choice questions generated on the fly by Gemini AI. Questions adapt to the topic and are available across all supported subjects. Dedicated quiz modes exist for DBMS and Python with structured question banks.

### 2. In-Browser Code Editor
A full coding environment that supports Python, Java, C, and C++. Code runs either via Docker containers (isolated execution) or falls back to local execution. After running, Gemini evaluates the solution and gives instant AI feedback on correctness, logic, and improvements.

### 3. Networking Playground
An interactive canvas where students drag and drop network devices — PCs, routers, and switches — and wire them together to build network topologies. Gemini AI evaluates the student's configuration against a generated scenario question, checking IP addressing, subnetting, gateway settings, and routing correctness.

### 4. SQL Practice Environment
Gemini generates beginner-friendly SQL questions with a pre-built table schema. Students write and run queries against a live in-memory SQLite database, see the actual output, and get AI evaluation on whether their query is correct with a score and suggested fix if needed.

### 5. English Fluency Assessor
Students record a spoken response to an AI-generated topic. The audio is processed through a full pipeline:
- Whisper ASR transcribes the speech
- A CRNN model detects filler words (um, uh, etc.)
- Librosa and Parselmouth analyze prosody: speech rate, pause ratio, pitch variability, and rhythm (nPVI)
- Gemini scores the transcript on vocabulary, grammar, coherence, clarity, and relevance
- The final report gives a detailed breakdown with grammatical mistakes and improvement tips

### 6. Syllabus Browser
Structured syllabi for all six subjects — Computer Networks, DBMS, Python, Java, C++, and C — so students always know what topics to cover and in what order.

### 7. Face Recognition Login
Students can register their face and log in using their webcam instead of a password, powered by face-api.js.

### 8. Progress Tracking & Gamification
Every activity contributes to a student's profile: total questions attempted, accuracy percentage, points earned, daily streaks, and level. A daily goal tracker keeps students consistent, and recent activity is shown on the dashboard.

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React 18, Vite, Tailwind CSS, Framer Motion, GSAP |
| Backend (API) | Node.js, Express.js, MongoDB, JWT |
| AI Backend | Python, FastAPI, Uvicorn |
| AI Engine | Google Gemini API (gemini-2.5-flash-lite) |
| Speech & Audio | OpenAI Whisper, Librosa, Parselmouth, CRNN model |
| Code Execution | Docker (with local fallback) |
| Auth | JWT + face-api.js face recognition |
